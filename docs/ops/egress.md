# 出站控制运维说明（AC-09）

## 默认行为

- 平台访问外部 HTTP(S)（模型上游、OIDC）全部经统一出站客户端。
- 白名单为空 = 拒绝一切外部访问；内网、回环、链路本地与云元数据地址（如 169.254.169.254）默认拦截。
- 不读取 `HTTP_PROXY` / `HTTPS_PROXY`（显式配置出站代理为 P1）。
- 只有部署配置里声明的数据库（`DATABASE_URL`）、Valkey（`REDIS_ADDR`）、对象存储端点不受白名单限制；对象存储客户端连接其他地址会被拒绝（D-38 第 6 条）。

## 管理

管理后台「安全 → 出站控制」：

- 出站白名单（仅超级管理员）：添加域名 / 通配域名 / IP / CIDR，可限定端口：**留空仅 443**，`*` 表示任意端口（有风险提示），例如 `443,8443`；可输入 URL 测试是否放行。修改即时生效（各实例最多 5 秒缓存）。
- 内网地址需显式添加 IP 或 CIDR 规则，会额外记录 `egress.private_allow` 审计。例如本地 vLLM：类型 `ip`，值 `10.0.0.5`，端口 `8000`。
- 出站日志（超级管理员、安全审计员只读）：按结果 / 主机 / 模块筛选，可导出 CSV（最多 10000 条）；不含请求体与密钥。
  查看、筛选、导出都会记审计（`egress.log.view / filter / export`，含筛选条件与条数），审计写失败时拒绝。
- 放行日志写失败时：模型对话照常（已有 fail-closed 调用审计）；其他调用（测试连接、OIDC 等）拒绝，原因「出站日志写入失败」。

## 升级

从 PR4 之前的版本升级时，首次启动会把已有模型供应商上游主机（以及已配置的 OIDC 签发方）加入白名单，来源标记为「升级迁移」，每条记录 `egress.rule.seed` 审计，只执行一次。
自动添加的条目使用上游 URL 的实际端口，白名单页显示「待复核」，请逐条核对后点「标记已复核」（记 `egress.rule.review` 审计），不需要的删除。

升级到 PR4b（D-38）时，一次性迁移旧的空端口条目：自动条目改为实际端口（找不到上游时 443），手动条目改为 `*` 以保持原放行范围，每条记 `egress.rule.ports_migrate` 审计。升级后请把不需要任意端口的手动条目改为具体端口。

## 排障

模型调用返回 403 `egress_denied`：在出站日志中按主机筛选查看拒绝原因（不在白名单 / 端口不允许 / 内网地址 / DNS 失败等），再按需添加规则。
