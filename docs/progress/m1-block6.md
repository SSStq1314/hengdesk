# M1 第六块：智能体运行时（进度与拆分）

依据 PRD §8 的 FR-20（智能体 CRUD、发布与可见范围）、FR-21（工具调用循环，最多 N 步、可配置）、FR-13 中「按智能体」的预算维度（D-37 第 12 条：智能体上线后补上），§9.5（智能体页面、用户旅程、实现逻辑与边界条件），§10 信息架构（`/agents` 智能体广场、`/admin/agents` 智能体管理），AC-03（只授权财务部的智能体对市场部列表不可见、详情 404），AC-06/07/08/11（经智能体发起的工具调用同样走审批、拒绝/超时结果交回模型、重启可续、trace 可还原），演示剧本第 7、8、9、10、11、14 步。本块只做 P0：不做多智能体协作、工作流（§9.5 明确不做）；工具代员工身份调用为 P1。

## 范围与技术要点

- **智能体定义**：`agents` 表保存「草稿」配置：名称、描述、系统提示词、开场白、模型、绑定的知识库（≤5）、绑定的工具（≤20）、最大工具步数（1–10，默认 5）。`agent_versions` 表保存每次「发布」的不可变快照（版本号递增）；员工对话一律使用**最新发布版本**，草稿改动不影响线上，直到再次发布。可从历史版本恢复为草稿。删除为软删除（保留版本与运行记录供审计）。
- **智能体 ACL**：复用 `acl` 表（resource_type=`agent`，主体为成员 / 部门含下级 / 角色，view/use/edit/manage）。创建需要 `agent.create`；创建者获得 manage；部门管理员创建时默认共享给其管辖部门（D-33 第 5 条，`authz.InitShare`），且只能共享到本部门子树（`authz.CanShareTo`）。**未发布的智能体只对有 edit 的人可见**（§9.5 边界条件；创建者默认 manage）。越权、不存在、未发布对无编辑权者一律 404，未登录 401。
- **绑定时校验**：保存配置时，模型必须是操作者本人可用的模型；知识库须本人有 view；工具须本人当前可用（`authz.ToolAccess`）。不可用一律 404（不暴露资源存在）。
- **运行时（复用已有能力）**：会话可绑定一个智能体（`conversations.agent_id` + `agent_version`）。生成时按以下顺序：组装系统提示词 → 知识库检索（kb_search 内置，复用第四块检索与 ACL 预过滤）→ LLM 工具循环（复用第五块：策略 → 审批挂起 → 出站 → 执行 → 审计），最大步数取智能体配置。**调用者权限 = 员工权限 ∩ 智能体授权**：员工须对智能体有 use；知识库按员工身份过滤；工具须员工当前可用；不可用的绑定资源**静默剔除**并在调试页提示；工具被禁用后智能体仍可用但模型看不到该工具；达到步数上限时返回已有结果并说明原因。
- **调试**：有 edit 的人可用草稿配置开「调试会话」（不必先发布），调试页右侧对话显示被剔除的资源。
- **运行记录与 trace 回放**：`agent_runs` 表每次生成一行（智能体、版本、会话、消息、发起人、trace_id、状态、步数、工具调用数、token、被剔除资源、起止时间）；有 manage 的人可在管理页查看本智能体的运行记录与单条详情（工具调用摘要、引用、审批单），审计员按 trace_id 在审计中心回放完整链路（复用第一块 `/admin/audit-logs/traces/:trace_id`）。
- **按智能体预算（FR-13）**：`usage_records.agent_id`；预算维度增加 `agent`；智能体会话的模型调用（含检索 embedding）计入该智能体。
- **异步 / 长任务**：PRD P0 未要求（§9.5 只要求对话内的单智能体循环；asynq 仅用于知识库索引）。本块不做，见待确认 1。
- **Web**：管理后台「智能体管理」（列表、编辑页左配置右调试、权限 Tab、发布 / 版本、运行记录）；工作台「智能体广场」（本人可用的已发布智能体，点击开始对话）；对话页显示当前智能体与开场白。
- **CI**：只用 mock 模型上游与本地假 MCP server，不读取任何真实密钥。

## 待确认（先按以下默认值实现，不阻塞开发）

1. **异步 / 长任务智能体**：PRD P0 只要求对话内的单智能体工具循环，未要求后台异步运行。默认：不做异步，智能体只在对话中同步运行（审批挂起与重启续跑复用第五块）。备选：P1 用 asynq 把智能体运行放到后台队列，完成后通知。
2. **谁能发布**：PRD 只写「发布按钮」。默认：有 manage 才能发布（发布会改变对他人的可见内容），有 edit 只能改草稿和调试。备选 a：edit 即可发布；备选 b：发布需管理员审批。
3. **未发布 / 草稿可见性**：默认：未发布只对有 edit 的人可见；已发布后，没有 edit 的人只看到最新发布版本的名称、描述、开场白，看不到系统提示词、绑定资源等内部配置。备选：对有 use 的人也展示系统提示词（便于理解行为）。
4. **绑定时的权限校验**：默认：配置模型 / 知识库 / 工具时，操作者本人必须当前可用，否则 404（防止借智能体绑定自己无权的资源）；从历史版本恢复时同样重新校验。备选：只在运行时按调用者过滤、配置时不校验。
5. **步数范围**：FR-21 写「最多 N 步、可配置」。默认 1–10，默认 5（与第五块对话一致）。备选：上限放宽到 20，或由管理员在系统设置里调整上限。
6. **部门管理员共享范围**：沿用 D-33：部门管理员创建的智能体默认共享 use 给其管辖部门（含下级），且只能共享到本子树内；组织管理员创建时默认仅本人。备选：部门管理员也可共享给全组织（需组织管理员审批）。
7. **超级管理员对智能体无隐式权限**：与知识库、工具一致，超级管理员也只按 ACL 看智能体（给自己授权记高风险审计，D-42）。备选：超级管理员 / 组织管理员在管理页可看到全组织智能体。
8. **删除**：默认软删除，删除后详情与会话一律 404，版本和运行记录保留供审计。备选：提供「下架」（保留但不可新开对话），本块不做。
