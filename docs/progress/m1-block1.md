## 4. 演示方式
```bash
cd deploy
./install.sh                         # 交互；可填初始审计员邮箱、证书 / 私钥路径（可选）
docker compose up -d --build
```
- 访问：未导入证书为 `http://<主机>:8080`；导入证书后为 `https://<主机>/`（80 / 8080 自动跳转）。
- 管理员：邮箱默认 `admin@hengdesk.local`，密码在 `deploy/.env` 的 `HENGDESK_ADMIN_PASSWORD`（`grep HENGDESK_ADMIN_PASSWORD deploy/.env`）。
- 安全审计员：在 `deploy/.env` 的 `HENGDESK_AUDITOR_PASSWORD`。
- 可看：成员 / 部门 / 角色页、部门 CSV 导入、/audit 审计日志（用审计员登录）、未指派审计员 / 未启用 HTTPS 的常驻提示、连续输错密码后的锁定与解锁。
- OIDC 需自备 IdP，配置见 `docs/dev/oidc.md`。
