# D-30 M1 工程默认项确认

> 与 `ai-office-platform/decisions.md` 中 D-30 内容一致（同步副本，产品经理确认）。
## D-30 M1 工程默认项确认（2026-11-02，产品经理）
- **会话**：M1 改为服务端会话，存 Valkey，可吊销，管理员可强制下线；连续登录失败 5 次锁定 15 分钟，阈值和时长可配置。修改密码或停用账号后，该用户的全部会话立即失效。
- **鉴权与审计**：未登录返回 401，已登录但无权限返回 404。GET 请求默认不记审计，但以下操作要记：导出、查看审计日志、下载知识库原文。**另外，越权尝试（返回 404 的资源访问）和登录失败也要记审计**，供安全追溯。
- **社区版许可**：确认 Apache-2.0（关闭 D-17 的待定项）。专业版能力放在独立的闭源模块里，社区版代码不依赖它们。
- **前端**：直接写中文，暂不引入 i18n 框架；文案集中放在常量文件里，方便以后迁移。
- **TLS**：服务本身不终止 TLS。默认 HTTP 8080，由客户前置的负载均衡处理 TLS。安装脚本**可选**导入证书，导入后由 nginx 启用 HTTPS 443。未启用 HTTPS 时，管理后台显示常驻提示（OIDC 和生产环境都需要 HTTPS）。对象存储端口只绑 127.0.0.1。
- **迁移**：M1 改为 ent + Atlas 版本化迁移文件。升级前自动备份数据库；迁移只向前执行，回滚方式是从备份恢复。
- **pgvector 复测**：放到 M1 知识库阶段，在大内存 runner 或目标硬件上跑，结果出来后由产品经理定稿 D-27 的数值。
