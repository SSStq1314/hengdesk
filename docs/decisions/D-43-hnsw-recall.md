# D-43 HNSW 召回参数（产品经理定）

> 同步自 `decisions.md` 第 423–429 行（产品经理，2026-11-04，补充 D-42，PR #44、#45）。下面是原文，未作改写；实现说明在后面。

1. **ef_search 默认值改为 1000**。50% 可见档召回 0.953，向量段约 51 ms，达到 D-42 的目标。允许按可见比例自适应调整 ef_search，但任何一档都不能低于各自的召回目标。
2. **100% 可见档也纳入考核**。理由：全员可见的企业知识库很常见，这一档很可能是用户最常遇到的情况。分阶段达标：
   - **M1**：recall@10 ≥0.93，当前 0.933 已经达到。
   - **M2**：recall@10 ≥0.95。做法是在不过滤的路径上单独调大 ef_search，并调整 HNSW 构建参数（m / ef_construction），然后复测。
3. **按知识库过滤**：同意列为 P1。
4. 复测在 16 GB 机器上已经达到延迟和越权目标。D-42 的「32 GB 推荐」继续保留，作为余量；M1 验收用的复测机器不强制要求 32 GB。
