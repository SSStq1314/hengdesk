# D-33 会话、锁定、密码与角色默认值确认

> 同步自 decisions.md（产品经理，2026-11-02）。原文如下，实现说明附后。

- **会话**：空闲 2 小时超时，最长 12 小时须重新登录；两项均可配置。
- **锁定**：按账号计数，被锁时返回 429。补充：
  - 同时按来源 IP 限速，避免攻击者批量锁死账号。
  - 账号不存在、密码错误、账号被锁三种情况，对外返回的提示统一，不泄露账号是否存在。
  - 组织管理员和超级管理员可手动解锁，解锁写入审计。
- **密码**：长度 8–72 字节；最小长度可配置，受监管客户常要求 12 位。内置一份常见弱密码黑名单。
- **角色与三员分立**：采纳五类角色及三员分立规则，系统至少保留一名有效超级管理员。补充：
  - 审计员的指派和撤销写入审计，审计员可见。
  - 没有指派审计员时，后台常驻提示。
  - install.sh 支持在安装时创建初始审计员。
- **部门管理员（M1）**：可查看成员、部门、角色，不可停用成员。可创建知识库和智能体，但默认只授权给本部门及其下级部门。共享到更大范围需要组织管理员操作。
- **审批人角色**：删除，改由 MCP 审批流按策略配置。
- **升级与备份**：M0 的数据库不支持原地升级，可接受。备份目录 `/backups`，默认保留最近 5 份（可配置）；磁盘剩余空间低于阈值时后台提示。

## 实现说明（工程）

- 锁定：按工程负责人后续指示，**账号被锁不再单独返回 429**。账号不存在 / 密码错误 / 已锁定 / 已停用统一返回 `401 邮箱或密码错误，或账号暂不可用`；只有按 IP 限速触发时返回 429（带 `Retry-After`）。未知账号也执行一次 bcrypt（dummy hash），响应时间一致。
- 按 IP 限速：Valkey 有序集合滑动窗口，`HENGDESK_LOGIN_IP_LIMIT`（默认 30 次）/ `HENGDESK_LOGIN_IP_WINDOW`（默认 10m），0 表示关闭。来源 IP 仅当 TCP 对端在 `HENGDESK_TRUSTED_PROXIES` 内时才取 `X-Forwarded-For`。
- 会话：`HENGDESK_SESSION_IDLE_TIMEOUT`（默认 2h）、`HENGDESK_SESSION_TTL`（默认 12h）。
- 密码：`HENGDESK_PASSWORD_MIN_LENGTH`（默认 8，范围 8–72）；弱密码黑名单取自 SecLists `10k-most-common.txt`（MIT），忽略大小写；密码不得包含邮箱 @ 前部分（≥3 字符时检查）。
- 审计员指派 / 撤销：`role.assign` / `role.revoke` 审计（detail 含 role、target_email），先写审计再变更（fail-closed）。
- 部门管理员共享范围：`authz.InitShare` / `authz.Share` / `authz.CanShareTo`，在 ACL 层实现；知识库、智能体实体落地时直接调用。
- 备份：`HENGDESK_BACKUP_KEEP`（默认 5），升级前备份成功后清理旧备份；`HENGDESK_DISK_LOW_PERCENT`（默认 10）低于阈值时后台常驻提示。
