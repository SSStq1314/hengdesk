# D-29 Go 工具链与依赖安全门禁

> 与 `ai-office-platform/decisions.md` 中 D-29 内容一致（同步副本）。
## D-29 Go 工具链改为 1.26 与依赖安全门禁（取代 D-24 中 Go 1.25）
- 决策日期：2026-11-02
- 拍板内容：
  - (a) 工具链始终使用 Go 官方仍在维护的版本，并锁定到最新补丁版本（2026-11-02 锁到 **go1.26.10**；2026-11-11 因 govulncheck 报出可达的 `net/http` MaxBytesReader 头竞争，且修复版本为 v1.26.11，补丁升到 **go1.26.11**。不豁免已有修复的可达漏洞）。Go 发布新的大版本后，在其发布周期内评估是否升级；1.27 已发布，等依赖都兼容后再安排升级，不阻塞 M0。
  - (b) CI 设 govulncheck 门禁：代码可达的漏洞阻断合并，不可达的只告警并记录豁免理由（仓库 `server/.govulncheck-exemptions.md`）。
  - (c) 依赖的安全更新（如 excelize 修复 GO-2026-6685）随本次一并升级。
  - D-24 中的「Go 1.25」已被本条取代，D-24 原文不改。
- 理由：Go 官方只维护最近两个大版本，1.25 已不再接收安全补丁；在 go1.25.14 下扫出 11 个标准库漏洞（包括 net/http 的 HTTP/2 问题），修复只在 1.26.9 及以后；excelize 有代码可达的 DoS 漏洞（GO-2026-6685），修复也要求 Go 1.26；受监管客户的安全评审不会接受已停止维护的工具链。参考 `/workspace/hengdesk-spikes/pdf-docx/REPORT.md` 第 7 节。
- 备选方案：继续用 Go 1.25 并锁定旧版本库，因为标准库漏洞无法修复，已否决。
